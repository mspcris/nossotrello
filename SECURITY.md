# Política de Segurança

## Versões suportadas

Este projeto usa deploy contínuo: apenas a versão em produção
(https://tarefas.camim.com.br) recebe correções de segurança.

## Como reportar uma vulnerabilidade

**Não abra uma issue pública.** Vulnerabilidades expostas em issues
podem ser exploradas antes da correção.

Reporte em privado por um destes canais:

- E-mail: cristiano@camim.com.br
- GitHub: aba **Security → Report a vulnerability** (private vulnerability
  reporting) deste repositório

Inclua, se possível:

- Descrição do problema e impacto
- Passos para reproduzir (URL, payload, conta usada)
- Sugestão de correção, se tiver

Você receberá uma resposta em até 7 dias. Pedimos que não divulgue a
falha publicamente até a correção estar em produção.

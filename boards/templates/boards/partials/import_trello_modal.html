Importar do Trello

Cole o link do board do Trello e tecle Enter. Abrimos o arquivo .json usando a sua sessão logada do Trello (funciona em board privado) — salve o arquivo e envie na 2ª opção abaixo.

2ª opção — enviar o arquivo JSON

Exporte no Trello em Menu → Imprimir, exportar e compartilhar → Exportar como JSON e envie aqui.

⚠️ O Trello costuma falhar nesse processo, entregando uma página HTML em vez do JSON (o arquivo começa com <!doctype html>). Se isso acontecer, use a opção 1 acima. O JSON válido começa com {.
💡 O quadro importado terá o nome "IMPORTANDO DO TRELLO EM [data]: [nome original]". Você poderá renomear depois.
